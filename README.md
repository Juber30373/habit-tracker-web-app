# Habit Tracker Web App project

## Files
- `index.html` - page structure
- `style.css` - complete styling and responsive design
- `script.js` - all application functionality
- `README.md` - instructions

## How to run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` with Live Server, or double-click `index.html`.
4. Use **+ Add Habit** to create habits.

## Features
- Dashboard
- Add, edit and delete habits
- Mark habits complete
- Current and best streaks
- Completion percentage
- 7-day and 14-day progress charts
- LocalStorage
- Responsive layout

The project has no backend and does not require Node.js or a database.
